# 웹 사이트와 웹 페이지

HTML 페이지를 직접 만들고, HTML·CSS·JavaScript가 각각 무엇을 맡는지 구분한다. 마지막에는 AI 채팅으로 계산기 페이지를 만들어 본다.

## 웹 사이트

웹 사이트는 인터넷에 콘텐츠가 올라가 있는 장소다. 접근은 웹 브라우저로 한다.

서버와 클라이언트는 요청(request)과 응답(response)으로 동작한다.

| 역할 | 하는 일 |
| --- | --- |
| 서버 | 사이트 내용을 보관한다. 클라이언트가 요청하면 파일을 보낸다. |
| 클라이언트 | 사이트 파일을 요청한다. 받은 코드를 브라우저에서 실행한다. |

주소창에 URL(Uniform Resource Locator)을 입력하면 서버가 파일(코드)을 보내고, 웹 브라우저가 그 코드를 실행해 화면을 그린다.

```text
브라우저 주소창에 URL 입력
        │
        ▼
   서버가 파일 전송
        │
        ▼
 브라우저가 코드를 실행해 화면을 그림
```

같은 주소라도 경로(`/`, `/docs/`, `/calculator/`)가 다르면 서버가 다른 파일을 돌려준다. 지금 만드는 MkDocs 사이트도 빌드 결과로 HTML 파일이 생기고, GitHub Pages가 그 파일을 대신 보내 주는 서버 역할을 한다.

## 웹 페이지의 언어, HTML

브라우저가 읽는 문서 형식은 HTML이다. 웹 페이지는 HTML 코드로 만들어진다. 브라우저에서 페이지를 연 뒤 소스 보기로 HTML을 직접 확인할 수 있다.

VS Code에서 `index.html`을 만들고 아래를 적은 뒤, 파일을 브라우저로 연다.

```html
<!DOCTYPE html>
<html>
    <head>
        <title>내 첫 페이지</title>
    </head>
    <body>
        <h1>안녕하세요</h1>
        <p>이게 web page입니다.</p>
    </body>
</html>
```

브라우저는 파일을 읽고 화면에 그린다. 제목은 `<h1>`, 문단은 `<p>`처럼 태그가 역할을 정한다. `<head>`는 화면에 바로 보이지 않는 정보(제목, 문자 인코딩, 스타일 연결)를 두고, `<body>`가 실제로 보이는 내용이다.

## 모양을 맡는 CSS

HTML만으로 색, 간격, 배치를 세밀하게 맞추기 어렵다. CSS(Cascading Style Sheets)로 색, 배경, 버튼 모양, 레이아웃 정렬을 정한다. 페이지 안에 넣을 때는 `<style>` 태그를 쓰고, 파일이 커지면 `.css` 파일로 분리해 `<link>`로 연결한다.

같은 HTML이라도 CSS가 바뀌면 보이는 모습이 달라진다. 글의 의미(제목인지 문단인지)는 HTML에 남기고, 보이는 규칙은 CSS에 둔다.

## 동작을 맡는 JavaScript

버튼을 눌렀을 때 계산이 되거나 글이 바뀌는 일은 JavaScript가 맡는다. HTML이 구조, CSS가 모양, JavaScript가 동작이다.

## 계산기 실습

1. HTML로 화면 틀을 만든다. 숫자 표시 영역과 버튼을 둔다.
2. CSS로 색, 버튼 크기, 정렬을 맞춘다.
3. JavaScript로 버튼 입력, 연산, 결과 표시를 넣는다.

AI 채팅에 “버튼이 있는 계산기 웹 페이지”처럼 역할을 나눠 요청하면 세 부분을 따로 받기 쉽다. 받은 코드는 그대로 두지 않고, 버튼 하나와 스타일 한 줄을 고쳐 보며 어느 파일이 바뀌는지 확인한다. 연습용 HTML은 `calculator/` 폴더의 `01_calcu.html`, `02_calcu.html`, `03_calcu.html`처럼 단계를 나눠 두면 나중에 비교하기 좋다.

## 정리

1. 웹 사이트는 인터넷에 콘텐츠가 게시된 장소이고, 브라우저는 그 장소에 접근하는 프로그램이다. 서버와 클라이언트는 요청과 응답으로 파일을 주고받는다.
2. 만들 때는 HTML과 CSS로 보이는 틀을 잡고, JavaScript로 기능을 넣는다.
