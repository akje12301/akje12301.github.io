    Markdown과 MkDocs

    웹 페이지는 HTML로 만들어지지만, 태그와 닫는 규칙을 글마다 손으로 쓰면 양이 빨리 늘어난다. GitHub는 Markdown으로 적은 문서를 HTML로 바꿔 보여 주는 기능을 가지고 있다. 이 노트는 그 길을 따라 Markdown으로 글을 쓰고, MkDocs로 HTML 사이트를 만든 뒤, 마지막에 배포한다.

    Markdown

    Markdown은 텍스트만으로 문서 구조(제목, 목록, 링크, 코드)를 적는 문법이다. #, *, - 같은 기호가 서식을 대신한다. 규칙이 적어서 HTML이나 다른 형식으로 바꾸기 쉽다.

    채팅 화면에 보이는 **굵게**나 코드 블록도 같은 계열이다. 미리보기가 달라도 원본은 글자 파일이다.

    자주 쓰는 기호

    # 제목 1
## 제목 2

**굵게** 와 *기울임*, ***굵게 기울임***

- 사과
- 바나나

1. 첫째
2. 둘째

문장 끝 공백 두 칸은  
줄바꿈이 된다.

[GitHub](https://github.com)

`print("hello world")`

    코드 여러 줄은 펜스 안에 둔다. 첫 줄에 언어 이름을 적으면 색이 입혀진다.

    def hello():
    print("Hello, World")

    인용은 > 로 시작한다.

    인용문이다.

    표는 헤더 다음에 |---| 구분선을 둔다.

    이름 나이 지역
    홍길동 17 서울
    김민철 16 부산

    이미지는 ![대체 텍스트](경로) 다. 사이트에 넣을 파일은 docs/ 기준으로 경로를 적는다.

    ![계산기 화면](images/calculator.png)

    HTML 주석 <!-- ... --> 은 페이지에 보이지 않는다. 초안 메모를 글 옆에 남겨 둘 때 쓴다.

    MkDocs가 하는 일

    MkDocs는 docs/의 Markdown을 읽어 HTML 사이트로 빌드하는 도구다. 페이지마다 HTML을 손으로 쓰지 않는다.

    docs/*.md  +  mkdocs.yml
        │
        ▼
   mkdocs build
        │
        ▼
   site/  (HTML, CSS, 검색 색인)

    mkdocs.yml의 nav가 왼쪽 목차 순서를 정한다. 파일만 폴더에 두고 nav에 올리지 않으면 테마에 따라 메뉴에 빠질 수 있다. 새 글을 만들면 파일과 nav를 같이 고친다.

    Material 테마(theme.name: material)는 목차, 검색, 한국어(language: ko)를 붙여 준다. 테마를 고르는 일은 글을 쓴 다음의 디자인이고, 배포 이후 디자인에서 잇는다.

    이 저장소에서의 흐름

    1. 루트의 .txt 초안에 기억을 남긴다. 이 파일은 사이트에 올라가지 않는다.
    2. 같은 주제를 docs/의 .md로 다시 쓰며 예시와 순서를 보강한다.
    3. mkdocs serve로 http://127.0.0.1:8000 에서 확인한다.
    4. 맞으면 GitHub에 올려 Pages로 배포한다.

    정리

    1. Markdown은 기호로 제목·목록·링크·코드를 적는 텍스트 문법이다.
    2. MkDocs는 그 파일을 HTML 사이트로 빌드한다.
    3. 설정은 mkdocs.yml, 본문은 docs/ 가 맡는다.
